# Data-Analytics-Final

This is an analysis of the Ultimate Games Dataset from https://www.kaggle.com/datasets/rudrakumargupta/ultimate-games-dataset-15k-games-43-features.

The analysis involves loading, cleaning, analyzing, and displaying.
The project was created in Jupyter Notebook.
It was completed in a group of 2 people.
